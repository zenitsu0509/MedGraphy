# Ayurveda dataset status

`ayurveda_dataset.csv` is imported into Neo4j as isolated `AyurvedaEntry` records. The rows, claims, scores, and source references remain unverified. `MENTIONS_HERB` means only that the herb string occurs in a row. Do not interpret graph links or the dataset's `Confidence` and `Auth_Score` values as evidence of efficacy or safety.

The raw CSV, workbook, and `Medicinal Leaf Dataset` image directory are intentionally excluded from Git because of their size and source/license review status. To use ingestion or images in a fresh checkout, place the supplied assets at those same paths locally.

## Audit snapshot

Generated by `ingest_ayurveda.py` on 2026-11-19 from the checked-in CSV:

- 10,000 rows and 10,000 unique row IDs
- 0 exact duplicate content rows after excluding the row ID
- 925 normalized problem labels and 28 normalized herb mentions
- 2,981 rows have an empty `Contraindications` field
- These six nonempty fields are identical across all 10,000 rows: `Authentication Notes`, `Classical Texts`, `Institutional Endorsements`, `Modern Evidence`, `Preventive Advice`, and `WHO Strategy Reference`
- CSV SHA-256: `3a9d99e3617e5fcfa5ccef0e13c89967dfcc157a01c028067626d0d525690de7`

The repeated boilerplate and templated looking distribution warrant verification against the cited primary source. The file does not establish an upstream publisher URL, publication date, jurisdiction, or redistribution license. The manifest at `source_manifest.json` deliberately records those as unknown. Confirm source identity and usage rights before redistribution or changing the preview status.

The leaf image folders are a separate image dataset. The UI shows an image only for an exact normalized match to a folder's parenthetical common name; that image is a leaf reference, not a product image or proof that a record's herb identity is correct. Candidate links to modern medicine ingredients are review leads only and are not automatically represented as graph relationships.
